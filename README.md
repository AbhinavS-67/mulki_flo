# Sustainable Mulki: Streamlit app

Two pages: Business Flowchart (home) and 3D Model.

Files
- app.py              entry point (set this as "Main file path" on Streamlit Cloud)
- views/              one small file per page
- html/               the two finished web pages
- requirements.txt    just streamlit

Run locally:  pip install -r requirements.txt  then  streamlit run app.py
